## 進行中・未着手の課題

### ① 業務アプリ（日報システム）の改修 ← 次の大きな仕事

**別リポジトリ** `incharvest/harvest-daily-report`（public・稼働中）
https://incharvest.github.io/harvest-daily-report/

React製の日報アプリが**すでにかなり作り込まれている**（`src/DailyReportApp.jsx` 約9.6万文字）。
音声入力・写真添付・全職員のまとめ表示・印刷など、必要な機能はほぼ実装済み。
**作り直すのではなく、土台だけ差し替える方針。**

**直すべき3点:**

1. **ログイン** — 現在 `src/DailyReportApp.jsx` の11〜14行目に
   **パスワードが平文で書かれており、publicなので誰でも読める**。
   → **Firebase Authentication**（メール+パスワード、無料枠）に置き換える
2. **データ保存** — 現在 localStorage（各端末に閉じるため、職員間で共有できない）
   → **Firestore**（無料枠で十分。職員10人×20件/日 = 上限の1%）
   → セキュリティルールを正しく書き、**公開前に「未ログインで読めないこと」を実測すること**
3. **公開設定** — `deploy.yml` が存在しないブランチを指している。
   あわせて README の初期パスワード表を削除

**設計方針（相談済み）:**
- 位置づけは**申し送りメモ**。正式な記録は別で管理しているので、保存義務の対象外
- **一定期間で自動削除**（例：90日）。残さないことが最大の漏えい対策
- 利用者は**氏名ではなく利用者番号＋イニシャル**で管理
- 音声入力は**スマホ標準キーボードのマイク**を使う（iPhoneではアプリ内音声認識が実用にならない）
- 音声データそのものは保存しない。テキスト化したものだけ

**着手前に確認すること:**
- [ ] 職員が現在このアプリを使っているか（使用中なら、各自のブラウザ内の日報を先に書き出す）
- [ ] README のパスワード（`admin` / `1234` 等）が実際に使われているものか
      → 使っているなら**公開されているので即変更**
