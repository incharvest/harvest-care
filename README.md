# 鍼灸マッサージ治療院 白 -HAKU-　訪問チラシ

このブランチ（作業場所）は、**鍼灸マッサージ治療院 白 -HAKU- の訪問鍼灸マッサージ**の
チラシ専用です。介護施設（デイサービス／住宅型有料老人ホーム）のサイトとは
完全に分けて管理します。

## 絶対に守るルール

- **このブランチに `.github/`（自動公開の設定）を置かない。**
  介護施設のサイトは `claude/*` ブランチへのプッシュで自動的にWeb公開されます。
  このブランチに設定ファイルが無い限り、プッシュしてもWebには一切出ません。
  チラシは手渡し配布用であり、Web公開しません。
- **介護施設のブランチ（`claude/review-harvest-care-sites-FhpVz`）と混ぜない。マージしない。**
- 介護施設のホームページから、この治療院への言及・リンクはしない。

## 【最重要】あはき法の広告規制

**チラシは「広告」に該当します。** あはき法第7条により、広告できる事項は
限定列挙されており、それ以外は書けません。ウェブサイトは原則として広告に
当たりませんが、印刷して配るチラシは完全に規制の対象です。

根拠：令和7年2月18日 厚生労働省「あはき・柔整広告ガイドライン」
https://www.mhlw.go.jp/content/10800000/001412682.pdf
（本フォルダに `参考_あはき柔整広告ガイドラインの概要_令和7年2月18日.pdf` として同梱）

### 書けること（これ以外は書けない）

- 施術者である旨・氏名・住所（「あん摩マッサージ指圧師（国家資格保有）」は可）
- 業務の種類（あん摩マッサージ指圧・はり・きゅう）
- 施術所の名称・電話番号・所在地（案内図、最寄駅からの道順・所要時間も可）
- 施術日・施術時間（受付時間、休療日）
- 医療保険療養費支給申請ができる旨
  **※「医師の同意が必要な旨」を明示する場合に限り広告可能**
  言い換え可：「医療保険により施術費用の一部負担で施術を受けることができます」
- 予約に基づく施術の実施
- **出張による施術の実施**（訪問できる地域、対応時間、「訪問施術の実施」「往療」の表現）
- 開設届出済である旨／駐車設備（駐車料金は書ける）
- もみりょうじ／やいと、えつ／小児鍼

### 書けないこと

- **施術料金**（広告可能事項に無い。書けるのは駐車料金のみ）
- **適応症**（「腰痛・膝痛・麻痺の方へ」等、どんな症状に効くか）
- **施術者の技能・施術方法・経歴**（「痛くない鍼」「○○療法」も不可）
- 効果を暗示するイラスト・写真（「病人が回復して元気になる姿のイラスト」が
  ガイドラインに明示の禁止例）
- 比較優良（「地域No.1」「県内唯一」）、虚偽・誇大
- 「診」の字（往診・訪問診療・初診・休診 → 往療・初検・休療 と書く）
- 「各種保険取扱い」という表記

### このチラシでの対応

上記に従い、料金表・症状の列挙・効果の説明はすべて外しています。
**要素を足すときは、必ず上の「書けること」に当てはまるか確認してください。**
金額は、お電話または訪問時の説明で口頭でお伝えする運用になります。

## デザインの考え方

屋号「白」を、色ではなく**余白**で表現しています。紙の白を主役にし、面を塗らず、
区切りは極細の罫と余白だけ。色は墨（文字）と朱（一点）のみで、
朱は**電話番号と料金の数字にしか使いません**。

紙面の主役は「**医療保険療養費の支給申請ができること**」と「**医師の同意が必要なこと**」です。
料金は広告できないため（上記参照）、患者さんとご家族が次に知りたい「保険が使えるのか」を
表面の中央に置き、金額はお電話・訪問時に口頭でお伝えする運用にしています。

この構成を成り立たせるために情報を絞っています。**要素を足すときは、
必ず何かを減らしてください。**埋めると「白」でなくなります。

### 色の決め方（根拠あり）

墨（`--sumi #1a1a1a`）と朱（`--shu #d3381c`）の2色だけです。朱は当初 `#b7282e`
（濃い赤）でしたが、次の理由で**赤だいだい寄り**に変更しました。

- 練馬区ユニバーサルデザインガイドラインは「**『赤』と『黒』を合わせて使用する場合は、
  『赤だいだい』や『オレンジ』を使用する**」としています（濃い赤は黒・こげ茶と
  見分けにくいため）。このチラシは墨＋朱なので、まさにこの組み合わせです。
- 二色覚シミュレーション（Viénot ら1999年の方法）で確認したところ、
  P型では `#b7282e` と灰色 `#3d3d3d` の輝度コントラストが **1.22:1**（ほぼ同じ）
  でしたが、`#d3381c` では **1.56:1**、D型では 2.02 → 2.62 に改善します。
- 白地に対するコントラストは `#d3381c` で **4.82:1** を保っており、
  WCAG AA（本文4.5:1）を満たします。

### 文字サイズの決め方（根拠あり）

練馬区UDガイドラインは「A4判の一般的な印刷物は**12ポイント以上**、
より読みやすくするには14ポイント以上」としています。高齢の方が読む前提のため、
本文（リード文・保険の説明）は**12pt**、ご案内の箇条書きは11pt、
補足の注記も**9pt以上**にしてあります。
文字を大きくした分、行数を増やさず、書く内容のほうを減らしています。

### 追加を検討してよい項目

「**開設届出済である旨**」は広告可能事項です（例：`○年○月○日 鹿児島県 開設届出済`）。
競合のチラシではほとんど使われていない一方、ケアマネジャー様に対しては
「県に届け出た正規の施術所である」という強い信頼材料になります。
**届出の年月日が分かれば**、裏面の施術所情報に1行足すことをおすすめします
（日付が不明のまま書くことはできないため、今は入れていません）。

## 写真について

写真枠は表面に1枠（写真①）、裏面に3枠（写真②③④）の計4枠で、**4枠すべて埋まっています**。
差し替え方と、必要な画素数は `photos/README.md` を参照してください。
印刷時は、写真が未定の枠から「写 真 ○」の文字が消えるようにしてあります。

他院から提供された写真を使う場合は、**顔と、白衣に入った他院名の刺繍が写らないよう
手元だけにトリミング**してください（ぼかしは不信感につながるため使わない）。


## 他院の調査（2026年9月）

チラシの形式・色を決めるにあたり、実際に配られている**鍼灸院・整骨院・訪問マッサージの
チラシ46点**を集めて、画素単位で色の面積を測りました。

| 項目 | 業界の実態（n=46） | このチラシ |
|---|---|---|
| 白・生成りの面積 | 平均 **22.1%** | **91.5%** |
| 主役の色 | オレンジ32.6% ／ 緑19.6% ／ 青15.2% ／ 青緑10.9% ／ 赤10.9% | 白＋墨＋朱 |
| 判型 | A4縦 27点・A4横 8点・三つ折り/帯 8点 | A4縦・A4横の両方 |

訪問鍼灸マッサージに限った14点では、A4縦が10点（71%）で、
ほぼ全点に「初回無料体験」「症状の一覧」「高齢者のイラスト」「巨大な電話番号」が
入っています。**症状の一覧と料金表は、あはき法上は書けない項目**ですが、
実態としては業界の定番になっています。

白を基調にした引き算のデザインは、この分野にはほぼ存在しません。
それが「白 -HAKU-」の名前と一致する、という判断でこの方向にしています。
