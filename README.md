# デイサービスチラシ（dayservice-flyer.html）

**A4横（landscape）両面**・印刷用のチラシです。デイサービスのホームページ（`dayservice.html`）と同じブランドカラー（フォレストグリーン × ゴールド）と実情報で構成されています。

> ※ `flyer.html` は別事業（訪問鍼灸マッサージ）のチラシなので混同しないでください。

---

## 1. ブラウザで確認・印刷

`dayservice-flyer.html` をブラウザで開き、印刷／PDF書き出し設定を以下にしてください。

| 項目 | 設定値 |
|------|--------|
| 用紙サイズ | A4（297mm × 210mm） |
| 用紙の向き | **横（landscape）** |
| 余白 | **なし** （`@page margin:0` 前提） |
| 背景のグラフィック | **オン** |
| 倍率 | 100% |
| 両面印刷 | 短辺とじ |

  └── bath-2.jpg                    ← 裏面ギャラリー（入浴設備）
images/rehab/                       ← 機能訓練の実写真
  └── rehab-1.jpg                   ← 裏面ギャラリー（機能訓練）
images/flyer/qr-web.svg             ← 公式サイトQR（プレースホルダー／要差し替え）

**全ての写真がハーベストの実写真**です。ストック画像は使用していません。実写真の差し替えは元ファイルを上書きすると、ホームページと同時に反映されます。

## 7. デザイン仕様

- **カラーパレット**：`#1e5c3a`（フォレストグリーン／ホームページのprimary）、`#c8963c`（ゴールド／accent）、`#e8a45c`（ウォームオレンジ）、`#f4f8f2`（クリーム）、`#fbfcf9`（ベース）、`#0e1f16`（文字）
- **フォント**：本文 = Noto Sans JP、見出し・キャッチ = Shippori Mincho（2書体構成）
- **セーフエリア**：紙端から左右 14mm 以内に重要要素を配置
- **塗り足し**：背景は紙端まで延長（@page margin:0 + overflow:hidden）
- **ホームページとの統一**：色・フォント・コピー・写真すべて `dayservice.html` と同じ
