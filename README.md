このブランチ（作業場所）は、**鍼灸マッサージ治療院 白 -HAKU- の訪問鍼灸マッサージ**の
チラシ専用です。介護施設（デイサービス／住宅型有料老人ホーム）のサイトとは
完全に分けて管理します。

## 【最重要】あはき法の広告規制

**チラシは「広告」に該当します。** あはき法第7条により、広告できる事項は
限定列挙されており、それ以外は書けません。ウェブサイトは原則として広告に
当たりませんが、印刷して配るチラシは完全に規制の対象です。

根拠：令和7年2月18日 厚生労働省「あはき・柔整広告ガイドライン」
https://www.mhlw.go.jp/content/10800000/001412682.pdf
（本フォルダに `参考_あはき柔整広告ガイドラインの概要_令和7年2月18日.pdf` として同梱）

### 書けること（これ以外は書けない）

- 施術者である旨・氏名・住所（「あん摩マッサージ指圧師（国家資格保有）」は可）
- 業務の種類（あん摩マッサージ指圧・はり・きゅう）
- 施術所の名称・電話番号・所在地（案内図、最寄駅からの道順・所要時間も可）
- 施術日・施術時間（受付時間、休療日）
- 医療保険療養費支給申請ができる旨
  **※「医師の同意が必要な旨」を明示する場合に限り広告可能**
  言い換え可：「医療保険により施術費用の一部負担で施術を受けることができます」
- 予約に基づく施術の実施
- **出張による施術の実施**（訪問できる地域、対応時間、「訪問施術の実施」「往療」の表現）
- 開設届出済である旨／駐車設備（駐車料金は書ける）
- もみりょうじ／やいと、えつ／小児鍼

### 書けないこと

- **施術料金**（広告可能事項に無い。書けるのは駐車料金のみ）
- **適応症**（「腰痛・膝痛・麻痺の方へ」等、どんな症状に効くか）
- **施術者の技能・施術方法・経歴**（「痛くない鍼」「○○療法」も不可）
- 効果を暗示するイラスト・写真（「病人が回復して元気になる姿のイラスト」が
  ガイドラインに明示の禁止例）
- 比較優良（「地域No.1」「県内唯一」）、虚偽・誇大
- 「診」の字（往診・訪問診療・初診・休診 → 往療・初検・休療 と書く）
- 「各種保険取扱い」という表記

### 「初回無料体験」について

**「無料体験」は、あはき法の広告可能事項に入っていない。**
広告できる事項は限定列挙であり、料金に関する事項は駐車料金しか書けない。
「無料」も料金の表示にあたるため、**広告としては書けない**と考えるのが妥当である。
（調査した他院46点のほぼ全点に「初回無料体験」があるが、これは業界に違反が
広く残っているだけで、根拠にはならない）

そのうえで、**無料体験を書ける場面はある。**ガイドラインは次のものを
「通常広告とは見なされないもの」として挙げている。

- **施術所内で掲示または配付するパンフレット等**
- **利用者からの申出に応じて送付するパンフレットや E-mail 等**
- ウェブサイト等（「認知性」を満たさないため原則として広告に当たらない）

したがって `-taiken` 版は、**次の3つの場面に限って使うこと。**

1. 施術所の中で手渡す・置いておく
2. 問い合わせてきた方に、求めに応じて送る
3. ウェブサイトに載せる

**ケアマネジャー様への配布やポスティングには使わないこと。**
これらは誘引性・特定性・認知性の3つを満たし、広告に当たる。
その場面では無印の版（`haku-flyer-a4-tate.html` / `-yoko.html`）を使う。

### このチラシでの対応

上記に従い、料金表・症状の列挙・効果の説明はすべて外しています。
**要素を足すときは、必ず上の「書けること」に当てはまるか確認してください。**
金額は、お電話または訪問時の説明で口頭でお伝えする運用になります。

## 【裏取り済】開設届出済である旨と、施術所の名称（令和7年2月18日ガイドライン）

`参考_あはき柔整広告ガイドラインの概要_令和7年2月18日.pdf` の原文で確認した（2026-09-21）。

### 「開設届出済」は書ける ── 創業年を伝える唯一の正しい方法

> **都道府県知事へ施術所開設に係る届出をした施術所である旨は広告可能。**
> 【広告可能な事項の例】（例）**○月○日　○○県　開設届出済**
> 【広告不可能な事項の例】（例）厚生労働省認定･認可、指定、都道府県知事認定･認可、指定 等

根拠：あはき広告告示 第4号「あはき師法第9条の2第1項前段の規定による届出をした旨」

**なぜこれが大事か**

- **創業年は広告可能事項に入っていない。**「2010年創業」とは書けない
- しかし **`2010年○月○日 鹿児島市 開設届出済`** なら書ける。
  **年が自然に伝わり、しかも法律上正しい**
- **無資格のリラクゼーション店には絶対に書けない一行**（そもそも届出ができない）

※ 告示の文言は「都道府県知事」だが、鹿児島市は中核市で市長への届出。
**「鹿児島市 開設届出済」で問題ないはずだが、書く前に保健所に一言確認するのが確実。**

### 施術所の名称 ── 今の「鍼灸マッサージ治療院 白」は適合している

> **【広告可能な名称の例】**
> ・業態を特定せずに「施術所（院）」と表記すること（例）○○施術所（院）
> ・提供する**施術業態**に「治療院（所）」を付けること
> 　（例）○○**鍼灸**治療院、○○鍼灸療院、○○鍼灸治療所 等
>
> **【広告不可能な名称の例】**
> ・病院又は診療所と誤解する恐れがあるものを含んでいる名称
> 　（例）○○**治療所**、**メディカル**、**クリニック**、リハビリ 等
> ・対象者を限定するもの（例）女性専門療院、交通事故専門、アスリート 等
> ・施術内容、技能、方法を含んでいる名称（例）不妊鍼灸、背骨専門、無痛治療 等
> ・効能を含んでいる名称、優良な施術所と思わせる名称（例）姿勢改善、小顔矯正 等

**判定**

- **「鍼灸マッサージ治療院 白」＝ 業態（鍼灸マッサージ）＋治療院。適合。変更不要**
- **「白治療院」は危うい。**業態が入らないため。
  検討に上がったが、**この理由で不採用**（2026-09-21）
- `haku.clinic` を外した判断も、これで裏が取れた（クリニックは名称として不可）

### あわせて確認できたこと

- **「国家資格保有」の表記も併せて広告することが可能** → チラシの `(国家資格保有)` は適合
- **「訪問施術の実施」の表現**は広告可能／**出張可能な範囲・地域**も広告可能
  → チラシの「訪問施術」「訪問できる地域」は適合
- **「診」は不可**（訪問診療、往診、診療日、診察、休診日、初診、再診 等）
  → 「往療」「施療」はよい。**チラシで「診」を使わないこと**
- **医療保険の言い換えも可能**
  「医療保険により利用者は施術費用の一部負担で施術を受けることができます」
  → チラシの表現は適合
- **比較優良広告は不可。**「知事へ届出済みの優良施術所です！」は**誇大広告の例として名指し**されている。
  届出済と書くのはよいが、**「優良」を足した瞬間にアウト**

## 訪問できる範囲と、健康保険の16kmルール

**治療院から直線16kmを超える訪問は、原則として健康保険が使えません。**
「交通費が出ない」だけではなく、**施術料そのものも保険の対象外**（全額自費）になります。

> ○片道16ｋｍを超える患家への訪問施術及び往療は、当該施術所からの訪問施術
> 又は往療を必要とする絶対的な理由がある場合に認められる。
> ○16ｋｍとは、先順位の患家からではなく、**施術所からの直線距離**である。
> ○**絶対的な理由がない場合は、往療料も施術料も支給できない。**

出典：はり、きゅう留意事項 第6章10・第7章5・第10章2／マッサージ留意事項
第5章11・第6章6・第9章2／H24疑義解釈資料 問29
（はり師、きゅう師及びあん摩・マッサージ・指圧師の施術に係る療養費の手引き
・静岡県 令和7年2月版に収載）

### 間違えやすい3点

## 治療院のメールアドレス（Gmail）の決め方

### 使える文字は3種類だけ（Google公式）

> ユーザー名にはアルファベット（a〜z）、数字（0〜9）、ピリオド（.）を使用できます。
> アンパサンド（&）、等号（=）、アンダースコア（_）、アポストロフィ（'）、
> **ダッシュ（-）**、プラス記号（+）、カンマ（,）、山括弧（<>）、
> 連続するピリオド（..）を使用することはできません。

出典：Gmail ヘルプ「Gmail のユーザー名を選択する」
https://support.google.com/mail/answer/9211434?hl=ja

**つまり、次のものは入れられません。**

- **ハイフン（-）** … `-HAKU-` の形は再現できない
- **日本語** … 「鍼灸」「白」などは不可
- アンダースコア（_）、プラス（+）

### ピリオド（.）は有無を区別しない

> ピリオドの数や位置が異なっても同一の Gmail アドレスと見なされます。

出典：Gmail ヘルプ「Gmail アドレスでのピリオドの扱い」
https://support.google.com/mail/answer/7436150?hl=ja

**`haku.kagoshima` と `hakukagoshima` は同じアカウント。**
片方が取られていたら、もう片方も取れない。**単語そのものを変えるしかない。**

### 大文字にすると `HAKU` を立てられる

Gmailは大文字・小文字を区別しない。登録は小文字でしておき、
**名刺だけ `HAKU.kagoshima@gmail.com` と刷る**ことができる。
ただし入力する人が迷わないのは小文字。**見栄えと無難さのトレードオフ。**

### 選ぶときの基準

1. **2語まで。**3語は名刺の連絡先の帯に収まらず、電話でも伝えにくい
2. **綴りが割れない単語を選ぶ。**
   `shinkyu` は shinkyu / shinkyuu / shinkyou に割れる。
   `chiryoin` は chiryoin / chiryouin に割れる。**電話で伝わらない**
3. **`massage` は入れない。**迷惑メール判定に引っかかりやすく、
   **医師への同意書のお願いが届かない**おそれがある。
   無資格のリラクゼーション店との区別もつきにくくなる
4. **誕生日や数字の羅列は入れない。**名刺に載ると安く見える

## デザインの考え方

屋号「白」を、色ではなく**余白**で表現しています。紙の白を主役にし、面を塗らず、
区切りは極細の罫と余白だけ。色は墨（文字）と朱（一点）のみで、
朱は**電話番号と料金の数字にしか使いません**。

紙面の主役は「**医療保険療養費の支給申請ができること**」と「**医師の同意が必要なこと**」です。
料金は広告できないため（上記参照）、患者さんとご家族が次に知りたい「保険が使えるのか」を
表面の中央に置き、金額はお電話・訪問時に口頭でお伝えする運用にしています。

この構成を成り立たせるために情報を絞っています。**要素を足すときは、
必ず何かを減らしてください。**埋めると「白」でなくなります。

### 写真をモノクロにしている理由

写真は4枚ともモノクロで印刷されます。カラーのままだと、灸の写真がオレンジ、
マッサージの写真がベージュ、鍼の写真が寒色…と、**3枚の色がばらついて
紙面に色が増えてしまう**ためです。モノクロにすると3枚が一つの組に見え、
**紙面で色を持つのは朱の電話番号だけ**になります。「白×墨×朱」という
この紙の作りが、そこで初めて成立します。

実装は `.photo img{ filter:grayscale(1) contrast(1.06) brightness(1.02); }` の
1行です。**カラーに戻すときは、この1行を消してください。**

### 色の決め方

墨（`--sumi #1a1a1a`）と赤（`--shu #c1121f`）の2色だけです。
**赤は血の色**という意味づけで、この深い赤（血赤）を選んでいます。
使うのは電話番号と見出し1本だけで、それ以外はすべて墨と白です。

色を変えるときは、HTMLの上のほうにある `--shu` の1行だけを書き換えてください。

**検討の記録（3案の比較）**

| 色 | 白地との比 | 灰（`#3d3d3d`）との比 C型 / P型 / D型 |
|---|---|---|
| `#b7282e`（最初の朱） | 6.25:1 | 1.73 / **1.22** / 2.02 |
| `#d3381c`（赤だいだい） | 4.86:1 | 2.24 / **1.56** / 2.62 |
| **`#c1121f`（血赤・採用）** | **6.28:1** | 1.74 / **1.15** / 2.07 |

- **白地に対しては血赤がいちばん強い**（6.28:1）。WCAG AA（本文4.5:1）を余裕で満たします。
- 一方、P型（1型色覚）の方には、赤と灰色の区別がつきにくくなります（1.15:1）。
  練馬区UDガイドラインが「赤と黒を合わせるときは赤だいだいを使う」と
  している理由がこれです。
- **ただしこのチラシでは実害が小さい**と判断しています。赤を使っているのは
  30ptの電話番号と見出しだけで、**大きさと位置で十分に目立つ**ためです。
  本文の中に赤い小さな文字を混ぜる、という使い方はしていません。

### 文字サイズの決め方（根拠あり）

練馬区UDガイドラインは「A4判の一般的な印刷物は**12ポイント以上**、
より読みやすくするには14ポイント以上」としています。高齢の方が読む前提のため、
本文（リード文・保険の説明）は**12pt**、ご案内の箇条書きは11pt、
補足の注記も**9pt以上**にしてあります。
文字を大きくした分、行数を増やさず、書く内容のほうを減らしています。

### 追加を検討してよい項目

「**開設届出済である旨**」は広告可能事項です（例：`○年○月○日 鹿児島県 開設届出済`）。
競合のチラシではほとんど使われていない一方、ケアマネジャー様に対しては
「県に届け出た正規の施術所である」という強い信頼材料になります。
**届出の年月日が分かれば**、裏面の施術所情報に1行足すことをおすすめします
（日付が不明のまま書くことはできないため、今は入れていません）。

## 写真について

写真枠は表面に1枠（写真①）、裏面に3枠（写真②③④）の計4枠で、**4枠すべて埋まっています**。
差し替え方と、必要な画素数は `photos/README.md` を参照してください。
印刷時は、写真が未定の枠から「写 真 ○」の文字が消えるようにしてあります。

他院から提供された写真を使う場合は、**顔と、白衣に入った他院名の刺繍が写らないよう
手元だけにトリミング**してください（ぼかしは不信感につながるため使わない）。
