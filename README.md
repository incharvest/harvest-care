# ハーベスト 印刷用チラシ（A4横・両面）

株式会社ハーベストの2事業のチラシです。どちらも **A4横（297×210mm）両面**、
事務所のプリンタでそのまま印刷できる作りにしています。

| チラシ | ファイル | 確認URL |
|---|---|---|
| マッサージ・リハビリ重視型デイサービス | `dayservice-flyer-a4.html` | https://incharvest.github.io/harvest-care/dayservice-flyer-a4.html |
| 住宅型有料老人ホーム | `resthome-flyer-a4.html` | https://incharvest.github.io/harvest-care/resthome-flyer-a4.html |

---

## 1. 印刷のしかた

上記URLをブラウザ（Chrome / Edge 推奨）で開き、画面上部の「印刷する」ボタン、
または `Ctrl + P`（Macは `⌘ + P`）を押して、次の設定にしてください。

| 項目 | 設定値 |
|------|--------|
| 用紙サイズ | A4 |
| 用紙の向き | **横** |
| 倍率 | **100%（実際のサイズ）** |
| 背景のグラフィック | **オン** ← 色が出ないときはここ |
| 両面印刷 | **長辺とじ** |

画面に出ている水色の説明バーは印刷されません。

### フチなし印刷は不要です
四辺 9mm の余白の内側にすべての要素を配置しているため、
一般的なプリンタの印刷できない範囲にかかりません。
用紙いっぱいまで色を敷きたい場合（印刷会社への入稿など）は別途ご相談ください。

（外部参照は表示できないことがあり、印刷事故のもとになるため）。

| ファイル | 読み取り先 |
|---------|-----------|
| `images/flyer/qr-line-dayservice.svg` | https://line.me/R/ti/p/@856izjct （デイサービス） |
| `images/flyer/qr-line-resthome.svg` | https://line.me/R/ti/p/@057duijv （有料老人ホーム） |

## 4. 掲載している内容の出どころ

チラシの数字・文言はホームページ（`dayservice.html` / `resthome.html`）と一致させています。
ホームページ側を更新したときは、チラシ側も次の箇所をご確認ください。

- 鍼灸マッサージ師の人数（現在 **6名**）
- ご利用対象（現在 **要介護1〜5**。要支援の方は対象外）
- 利用料金・月額費用（介護報酬改定・費用改定のたびに要確認）
- 定員、営業日・営業時間、送迎エリア
- 有料老人ホームの空室状況（チラシには具体的な室数を載せていません。
  載せる場合は `resthome-flyer-a4.html` 内のコメントの手順をご覧ください）

## 7. ケアマネジャー向けページからの配布

`caremanager.html` の「ご案内資料（チラシ）」セクション（送迎エリアとお問い合わせの間）から、
ケアマネジャー様が自分でチラシを保存・印刷できるようにしています。

| 置き場所 | 中身 |
|---|---|
| `assets/flyers/harvest-dayservice-flyer.pdf` | デイサービスのチラシPDF（両面） |
| `assets/flyers/harvest-resthome-flyer.pdf` | 有料老人ホームのチラシPDF（両面） |
| `assets/flyers/thumb-*.jpg` | セクションに出す表紙サムネイル |

**チラシのHTMLを直したら、このPDFとサムネイルも作り直してください。**
作り直さないと、ケアマネジャー様が古いチラシをダウンロードしてしまいます。
（ヘッドレスChromeでA4横・背景ありでPDF化 → 表面を長辺900pxのJPEGにしてサムネイルに）
