# デイサービスチラシ（flyer.html）差し替えガイド

A4両面・印刷用のチラシです。`flyer.html` をブラウザで開き、印刷時に「背景のグラフィック」をオン、余白「なし」に設定すると、表面・裏面の2ページがそのまま印刷／PDF書き出しできます。

---

## 1. ファイル構成

```
flyer.html                          ← 単一HTMLファイル（CSSは内包）
images/flyer/
  ├── photo-hero.svg                ← 表面メインビジュアル
  ├── icon-warmth.svg               ← 特徴①アイコン
  ├── icon-care.svg                 ← 特徴②アイコン
  ├── icon-community.svg            ← 特徴③アイコン
  ├── photo-dining.svg              ← 裏面ギャラリー（食堂）
  ├── photo-bath.svg                ← 裏面ギャラリー（お風呂）
  ├── photo-rehab.svg               ← 裏面ギャラリー（機能訓練室）
  ├── photo-rec.svg                 ← 裏面ギャラリー（レクスペース）
  ├── map.svg                       ← 簡易マップ
  ├── qr-web.svg                    ← 公式サイトQR（表・裏で使い回し）
  └── qr-line.svg                   ← LINE友だち追加QR
```

実際の写真（JPG/PNG）に差し替える際は、SVGと同じファイル名（拡張子のみ変更）にして上書きするか、`flyer.html` 内の `src` を書き換えてください。

## 4. 印刷設定

| 項目                       | 設定値                                |
|----------------------------|---------------------------------------|
| 用紙サイズ                 | A4（210mm × 297mm）                    |
| 余白                       | **なし** （`@page margin:0` 前提）    |
| 背景のグラフィック         | **オン**                              |
| 倍率                       | 100% （拡大縮小しない）              |
| 両面印刷                   | 長辺とじ                              |

ブラウザは Chrome / Edge を推奨。Safari でも印刷可能ですが、フォント表示が若干異なる場合があります。

---

## 5. デザイン仕様メモ

- **カラーパレット**：`#E8A87C`（メイン アプリコット）、`#85C1A3`（サブ セージグリーン）、`#F4E4C1`（クリーム）、`#C38D5E`（テラコッタ）、`#FBF9F4`（ベース白）、`#3D3128`（文字色）
- **フォント**：本文 = Noto Sans JP、見出し・キャッチ = Shippori Mincho（2書体のみで構成）
- **セーフエリア**：紙端から左右上下とも 14mm 以内に重要要素を配置
- **塗り足し**：背景は紙端まで延長（@page margin:0 + overflow:hidden）

---

## 6. 編集時の注意

- 単位は `mm` 基準（ピクセル換算ズレ防止）。要素サイズを変える際は mm を維持してください。
- セクション高さは表面・裏面とも合計 297mm ぴったりに調整済みです。要素を増減する場合は、他のセクションの `height` をそれに合わせて調整してください。
- 写真をJPG/PNGに差し替えた際、ファイル拡張子に合わせて `<img src>` を書き換えてください。
