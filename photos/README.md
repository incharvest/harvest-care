# 写真の入れ方

このフォルダに写真ファイル（jpg）を置き、チラシのHTMLを1行だけ書き換えます。

## 手順

1. 写真をこのフォルダに入れる（例：`shisyutsu-01.jpg`）
2. `haku-flyer-a4-tate.html`（または `-yoko.html`）を開き、次の行を探す

```html
<div class="photo"><span>写 真 ①</span></div>
```

3. その行を、次のように書き換える

```html
<div class="photo"><img src="photos/shisyutsu-01.jpg" alt=""></div>
```

枠のサイズに合わせて自動で切り抜かれます（中央基準）。
写真が無い枠はそのままにしておけば、やわらかいベージュの面として成立します。

## 写真を選ぶときの注意

- **顔が写らないもの**を選ぶ（ぼかしではなく、トリミングで画面外に出す）
- **白衣の刺繍など、他院名や個人名が写らないもの**
- 「鍼が刺さっている」写真は、鍼が苦手な方には抵抗があるため、
  表面は手技（マッサージ）中心、鍼の写真は裏面に置くのが無難
