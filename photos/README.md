# 写真の入れ方

写真は `photos/` フォルダに置き、チラシのHTMLを1行だけ書き換えます。
枠は表面に1つ（写真①）、裏面に3つ（写真②③④）の計4つです。

**いちばん簡単なのは、チャットに写真を送ってこちらで入れてもらうことです。**
自分で入れる場合は以下の手順です。

---

## A. GitHub のサイト上でやる（パソコンのアプリは不要）

### 1. 写真をアップロードする

1. https://github.com/incharvest/harvest-care を開く
2. **ファイル一覧の左上にある枝マーク（ブランチ）のボタンを押し、
   `claude/haku-chirashi` を選ぶ** ← ここを間違えないこと
3. `photos` フォルダをクリックして中に入る
4. 右上の **「Add file」→「Upload files」**
5. 写真をドラッグ＆ドロップ（複数まとめてでOK）
6. 下までスクロールして **「Commit changes」** を押す
   - 「Commit directly to the `claude/haku-chirashi` branch」が
     選ばれていることを確認する

**ファイル名は半角の英数字にしてください**（例：`shoumen-01.jpg`）。
日本語のファイル名は、表示されないことがあります。

### 2. HTMLを1行書き換える

1. 同じブランチで `haku-flyer-a4-tate.html`（縦）を開く
2. 右上の **鉛筆マーク（Edit this file）** を押す
3. `Ctrl + F`（Macは `⌘ + F`）で `写 真 ①` を探す
4. 次の行を

```html
<div class="photo"><span>写 真 ①</span></div>
```

  こう書き換える（`shoumen-01.jpg` の部分は自分のファイル名に）

```html
<div class="photo"><img src="photos/shoumen-01.jpg" alt=""></div>
```

5. 右上の **「Commit changes」** → もう一度「Commit changes」
6. A4横も使うなら、`haku-flyer-a4-yoko.html` にも同じことをする

写真は枠のサイズに合わせて自動で切り抜かれます（中央基準）。
写真を入れない枠はそのままでかまいません。うすいグレーの面として成立します。

---

## B. 確認のしかた

書き換えたあと、ファイル一覧から `haku-flyer-a4-tate.html` を開いても
GitHub上では中身のコードしか見えません。**仕上がりを見るには、
チャットで「写真を入れた版を見せて」と言ってください。**
印刷用のPDF・JPEG・Wordを作り直してお渡しします。

### 確認しておきたいこと

- **著作権**：ファイル名から、鍼灸院ポータル「しんきゅうコンパス」の掲載用に
  撮影された写真と思われます。撮影者（カメラマン）に権利が残っている場合があるため、
  **チラシへの使用について、写真をくださった院長先生に確認**してください。
- **被写体の同意**：顔は写っていませんが、身体が写っています。
  撮影時に配布物への使用の同意が取れているか、あわせてご確認ください。

## 注意

- **このブランチは Web に公開されません。**`.github/`（自動公開の設定）を
  置いていないため、写真を上げてもインターネットには出ません。
- ただし GitHub のリポジトリ自体を見られる人には見えます。
  患者さんが写っている写真は、**ご本人の同意を得てから**上げてください。

## 写真を選ぶときの注意

- **顔が写らないもの**を選ぶ（ぼかしではなく、トリミングで画面外に出す）
- **白衣の刺繍など、他院名や個人名が写らないもの**
- 「鍼が刺さっている」写真は、鍼が苦手な方には抵抗があるため、
  表面は手技（マッサージ）中心、鍼の写真は裏面に置くのが無難
- **効果を暗示する写真は使えません**（あはき法。詳しくは親フォルダの README）
  施術所の外観・道具・風景は問題ありません。
