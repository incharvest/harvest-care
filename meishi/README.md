1. **屋号を主役にした。** 校正では「白 -HAKU-」が左下の隅にあり、いちばん大きいのが

### 表面の組み方

```
┌─────────────┬──────────────────────┐
│  白          │   代　表              │   ← 上段：屋号 ｜ 人
│  ▔▔（朱）    │   白根　寛征          │
│  HAKU        │   あん摩マッサージ指圧… │
│  鍼灸マッサージ│                      │
│  治療院      │                      │
├─────────────┴──────────────────────┤
│ 株式会社ハーベスト        TEL・FAX 099-296-9843 │ ← 下段：連絡先の帯
│ 〒891-0103 鹿児島市皇徳寺台三丁目58-1            │
└────────────────────────────────────┘
```

**上段＝「誰か」を伝える段、下段＝「どこに連絡するか」の段**、と役割で切ってあります。
縦の細い罫（0.2mm・薄いグレー）で屋号と氏名を分け、
下段は横の細い罫で切り離しています。罫は**囲まず、切るためだけに**使っています。

### なぜこの形にしたか

1. **横型は「左に屋号・右に名前」が読みやすい。**日本語の名刺は横書きなので、
   視線が左上→右へ流れる。屋号を左に固めると、受け取った瞬間に「白」が目に入る
2. **連絡先を1本の帯にまとめた。**A/B/C では連絡先が縦に積み上がって行数を食っていた。
   左右に振り分けると2行で収まり、**上段に余白を大きく残せる**。この余白が「白」そのもの
3. **朱の線を7mmだけに絞った。**B案の朱の帯は断裁（カット）に掛かるため塗り足しが要る。
   D案の線は内側にあるので**塗り足し無しで印刷できる**。刷りやすさが違う
4. **「代表」を小さく、お名前を大きく。**外注校正は逆で肩書が目立っていた

### 裏面

チラシと同じキャッチ「通院がむずかしい方のお宅へ、伺います。」を主役に、
その下に**広告できる事項だけ**を置いています。

| 記載 | あはき法上の根拠 |
|---|---|
| 国家資格をもつ施術者が… | 施術者の資格は広告可能事項 |
| **医療保険療養費の支給申請ができます。※ 医師の同意が必要です。** | 告示で認められた事項。**ただし「医師の同意が必要」の明示が条件**。必ずセットで書く |
| 訪問地域／施術日・受付 | 施術日時・所在地は広告可能事項 |

表面には**業務の種類**（あん摩マッサージ指圧・はり・きゅう）をお名前の下に入れています。

右上に小さく「白」を再掲。裏だけ見ても、どこの名刺か分かるようにしています。

### アピールポイントの並べ方（ご一任いただいた部分）

置く順番を **「誰が来るか → 費用の不安 → 来られる範囲」** にしました。

- **1番目に国家資格。**ケアマネジャー様が最初に確かめるのは
  「無資格の慰安マッサージではないか」。ここを冒頭に置く
- **2番目に医療保険。**ご家族がいちばん気にするのは費用。
  赤字にしているのは名刺で**唯一の色**で、視線がそこへ行くため
- **3番目に地域と時間。**「頼めるかどうか」の最終判断に必要な情報。
  下段に固定してあるので、探さずに見つかる

**入れなかったもの**：料金、症状名（肩こり・腰痛など）、「効きます」の類。
症状名や効能はあはき法で広告できません（`README.md` に一覧があります）。
料金は書けますが、名刺に入れると**値段で選ぶ相手**を呼び込むことになるため外しました。

## 関連事業（デイサービス・有料老人ホーム）を入れるか

**結論：表面には入れない。入れるなら裏面の最下部に、小さく。**

- 表面に足すと、せっかく直した「屋号が主役」が また崩れる。
  外注校正の失敗がまさにそれだった
- 名刺は**1枚で1つのことしか伝わらない**。3事業を伝える役割は、
  FAX送付状とチラシがすでに担っている
- 患者様・ご家族にも渡るものなので、デイサービスや有料老人ホームが
  並んでいると「何の人か」が分かりにくくなる

裏面の最下部に入れた版を `a_group.html` / `b_group.html` として用意した。
**ケアマネジャー様に渡す用**として使い分けるのも手。

> [!tip] 2種類を持ち分ける手もある
> 代表（白根様）は「株式会社ハーベスト代表」としても動く。
> **治療院の名刺**と**会社代表の名刺**を別に作り、相手で使い分けるのが
> いちばん筋が通る。会社代表の名刺が必要なら、そちらは3事業を並記した
> 別のデザインで作る。

### なぜ極細フォントを「白」だけに限るか

ひな明朝は美しいが**線が細すぎて、小さい文字にすると印刷でかすれる**。
とくに名刺の6pt前後の連絡先に使うと、紙質によっては読めなくなる。
**大きい字＝極細、小さい字＝太め**が原則。

## 訪問できる地域と、健康保険の16kmルール（2026-09-21 修正）

オーナーから「法律上、片道18km範囲では」とご指摘をいただき、確認しました。
**正しくは16kmでした。**根拠は以下のとおりです。

### 根拠

> ○片道16ｋｍを超える患家への訪問施術及び往療は、当該施術所からの訪問施術
> 又は往療を必要とする絶対的な理由がある場合に認められる。
> ○16ｋｍとは、先順位の患家からではなく、**施術所からの直線距離**である。
> （施術所を有さない場合は、保健所に届出されている住所地からの距離）
>
> ○**絶対的な理由がない場合は、往療料も施術料も支給できない。**

出典：はり師、きゅう師及びあん摩・マッサージ・指圧師の施術に係る療養費の手引き
（静岡県・令和7年2月版）／はり、きゅう留意事項 第6章10・第7章5・第10章2、
マッサージ留意事項 第5章11・第6章6・第9章2／H24疑義解釈資料 問29

### ここが大事な3点

1. **直線距離です。**道のり（実際に車で走る距離）ではありません。地図上の直線
2. **起点は治療院（皇徳寺台三丁目58-1）です。**前の患者様のお宅からではありません
3. **16kmを超えると、往療料だけでなく施術料も保険が使えません。**
   「交通費が出ないだけ」ではなく、**施術そのものが全額自費**になります。
   だからこそ範囲をはっきり書く意味があります

## 業務の書き方（2026-09-21 確定）

**「あん摩マッサージ指圧・はり・きゅう」**（師を付けない・業務の種類）で確定しました。
6案すべて同じ表記です。

### なぜ「師」を付けないほうを選んだか

一度は資格名（あん摩マッサージ指圧師・はり師・きゅう師）を入れましたが、
**オーナーのご判断で業務表記に戻しました。**判断の理由は次のとおりです。

1. **「師」を付けると、人ごとに書き分けが必要になる。**
   資格名は**その人が持っている免許**なので、保有内容が違えば表記も変わります。
   白根様は3つ、桧物様は2つ。**同じ治療院の名刺なのに中身が揃わない**
2. **業務表記なら、全員同じ1行で済む。**
   「あん摩マッサージ指圧・はり・きゅう」は**施術所（治療院）の業務**なので、
   誰の名刺でも同じ。並べたときに揃う
3. **すっきりする。**「師」が3回出ると字数が20字になり、横型では改行が起きました。
   業務表記は17字で1行に収まります
4. **ケアマネジャー様が知りたいのは「この治療院に頼めるか」。**
   個人の免許構成ではなく、**治療院として何ができるか**のほうが実用的です

### 法令上も問題ありません

あはき法の広告可能事項には「**業務の種類**」が明記されています。
「あん摩」「マッサージ」「指圧」「はり」「きゅう」を並べる書き方は、
**そのまま認められた書き方**です。「師」が無いと違法になる、ということはありません。

### 採用しなかった案：資格名（師つき）を入れる

記録として残します。**もし将来入れ直すなら**、正しい表記は次のとおりです。

| 正しい書き方 | 補足 |
|---|---|
| **あん摩マッサージ指圧師** | **これで1つの免許**。「あん摩師」「マッサージ師」「指圧師」と分かれてはいない |
| **はり師** | 法律の表記は**ひらがな**。「鍼師」ではない |
| **きゅう師** | 同上。「灸師」ではない |

> [!warning] 「鍼灸師」という資格はありません
