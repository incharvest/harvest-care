# 名刺 4案

外注先の校正がしっくり来ない、というご相談を受けて作った対案です。
チラシと同じ設計思想（白×墨×赤、余白で「白」を出す）で組んでいます。

| ファイル | 案 | 判型 | 書体 |
|---|---|---|---|
| `a.html` / `名刺A案_縦型.pdf` | **A案「一字」** | 縦型 55×91mm | 明朝 |
| `b.html` / `名刺B案_横型.pdf` | **B案「朱の一本線」** | 横型 91×55mm | ゴシック中心 |
| `c.html` / `名刺C案_横型.pdf` | **C案「白を敷く」** | 横型 91×55mm | 明朝＋ゴシック |
| `a_group.html` / `名刺A案_縦型_関連事業あり.pdf` | A案の裏に関連事業を入れた版 | 〃 | 〃 |
| `b_group.html` / `名刺B案_横型_関連事業あり.pdf` | B案の裏に関連事業を入れた版 | 〃 | 〃 |
| `d.html` / `名刺D案_横型.pdf` | **D案「二段組」** | 横型 91×55mm | 明朝＋ゴシック |

書体は4案とも **大きな「白」＝ひな明朝／文字＝しっぽり明朝／小さな文字＝Zen Kaku Gothic New**。

PDFは各2ページ（1ページ目＝表面、2ページ目＝裏面）、**仕上がり実寸**です。

## 外注の校正から変えた点

1. **屋号を主役にした。** 校正では「白 -HAKU-」が左下の隅にあり、いちばん大きいのが
   お名前、次が株式会社ハーベストだった。これでは「白」が覚えられない。
2. **業務の種類を明記した。**「あん摩マッサージ指圧・はり・きゅう」はあはき法で
   広告できる事項。ケアマネジャー様が**無資格の慰安マッサージと見分ける唯一の手がかり**。
   校正には一行も無かった。
3. **裏面を働かせた。** 校正の裏面A/B/Cは地の色がわずかに違うだけで、
   ほぼ空白だった。4案とも裏面の役割を変えてある（下記）。
4. **チラシと揃えた。** 赤は `#c1121f`（血の色）。チラシと同じ。

## 4案の違い（見た目ではなく「裏面の役割」で分けている）

- **A案**：裏はほぼ白。屋号と訪問エリアだけ。いちばん引き算が効いている
- **B案**：裏に業務・訪問地域・施術日・保険の一文。**ケアマネジャー様に渡す前提**で情報量が最も多い
- **C案**：裏はチラシと同じキャッチ「通院がむずかしい方のお宅へ、伺います。」が主役
- **D案**：C案のキャッチに、B案の情報量を足したもの。**横型の決定版**（下記）

## D案「二段組」（2026-09-21 追加・横仕様）

A/B/C を見たうえで「横仕様で、これまでの経緯を踏まえて」とご依頼をいただいて
作った案です。**横型の中でいちばん情報が整理されている**のがD案です。

### 表面の組み方

```
┌─────────────┬──────────────────────┐
│  白          │   代　表              │   ← 上段：屋号 ｜ 人
│  ▔▔（朱）    │   白根　寛征          │
│  HAKU        │   あん摩マッサージ…    │
│  鍼灸マッサージ│                      │
│  治療院      │                      │
├─────────────┴──────────────────────┤
│ 株式会社ハーベスト        TEL・FAX 099-296-9843 │ ← 下段：連絡先の帯
│ 〒891-0103 鹿児島市…      inc.harvest@gmail.com │
└────────────────────────────────────┘
```

**上段＝「誰か」を伝える段、下段＝「どこに連絡するか」の段**、と役割で切ってあります。
縦の細い罫（0.2mm・薄いグレー）で屋号と氏名を分け、
下段は横の細い罫で切り離しています。罫は**囲まず、切るためだけに**使っています。

### なぜこの形にしたか

1. **横型は「左に屋号・右に名前」が読みやすい。**日本語の名刺は横書きなので、
   視線が左上→右へ流れる。屋号を左に固めると、受け取った瞬間に「白」が目に入る
2. **連絡先を1本の帯にまとめた。**A/B/C では連絡先が縦に積み上がって行数を食っていた。
   左右に振り分けると2行で収まり、**上段に余白を大きく残せる**。この余白が「白」そのもの
3. **朱の線を7mmだけに絞った。**B案の朱の帯は断裁（カット）に掛かるため塗り足しが要る。
   D案の線は内側にあるので**塗り足し無しで印刷できる**。刷りやすさが違う
4. **「代表」を小さく、お名前を大きく。**外注校正は逆で肩書が目立っていた

### 裏面

チラシと同じキャッチ「通院がむずかしい方のお宅へ、伺います。」を主役に、
その下に**広告できる事項だけ**を置いています。

| 記載 | あはき法上の根拠 |
|---|---|
| 国家資格を有する施術者が… | 施術者の資格は広告可能事項 |
| **医療保険療養費の支給申請ができます。※ 医師の同意が必要です。** | 告示で認められた事項。**ただし「医師の同意が必要」の明示が条件**。必ずセットで書く |
| 訪問地域／施術日・受付 | 施術日時・所在地は広告可能事項 |

右上に小さく「白」を再掲。裏だけ見ても、どこの名刺か分かるようにしています。

### アピールポイントの並べ方（ご一任いただいた部分）

置く順番を **「誰が来るか → 費用の不安 → 来られる範囲」** にしました。

- **1番目に国家資格。**ケアマネジャー様が最初に確かめるのは
  「無資格の慰安マッサージではないか」。ここを冒頭に置く
- **2番目に医療保険。**ご家族がいちばん気にするのは費用。
  赤字にしているのは名刺で**唯一の色**で、視線がそこへ行くため
- **3番目に地域と時間。**「頼めるかどうか」の最終判断に必要な情報。
  下段に固定してあるので、探さずに見つかる

**入れなかったもの**：料金、症状名（肩こり・腰痛など）、「効きます」の類。
症状名や効能はあはき法で広告できません（`README.md` に一覧があります）。
料金は書けますが、名刺に入れると**値段で選ぶ相手**を呼び込むことになるため外しました。

## 関連事業（デイサービス・有料老人ホーム）を入れるか

**結論：表面には入れない。入れるなら裏面の最下部に、小さく。**

- 表面に足すと、せっかく直した「屋号が主役」が また崩れる。
  外注校正の失敗がまさにそれだった
- 名刺は**1枚で1つのことしか伝わらない**。3事業を伝える役割は、
  FAX送付状とチラシがすでに担っている
- 患者様・ご家族にも渡るものなので、デイサービスや有料老人ホームが
  並んでいると「何の人か」が分かりにくくなる

裏面の最下部に入れた版を `a_group.html` / `b_group.html` として用意した。
**ケアマネジャー様に渡す用**として使い分けるのも手。

> [!tip] 2種類を持ち分ける手もある
> 代表（白根様）は「株式会社ハーベスト代表」としても動く。
> **治療院の名刺**と**会社代表の名刺**を別に作り、相手で使い分けるのが
> いちばん筋が通る。会社代表の名刺が必要なら、そちらは3事業を並記した
> 別のデザインで作る。

## 書体（フォント）

### 推奨の組み合わせ（採用済み）

| 使い場所 | 書体 | 理由 |
|---|---|---|
| 大きな「白」 | **Hina Mincho（ひな明朝）** | 線が極端に細く、字が「余白の輪郭」になる。屋号と一致する |
| 屋号・氏名・見出し | **Shippori Mincho（しっぽり明朝）** | 和の品格があり、小さくしても読める |
| 連絡先などの小さな文字 | **Zen Kaku Gothic New** | 数字と英字が明快。小さい字でつぶれない |

**切り替え方**：`_common.css` の `.mi{ font-family: … }` が明朝の指定。
大きな「白」だけ別にする場合は `a.html` の `.mark .k` と `.back .k` に
`font-family:'Hina Mincho',serif;` を足す。

### なぜ極細フォントを「白」だけに限るか

ひな明朝は美しいが**線が細すぎて、小さい文字にすると印刷でかすれる**。
とくに名刺の6pt前後の連絡先に使うと、紙質によっては読めなくなる。
**大きい字＝極細、小さい字＝太め**が原則。

`https://fonts.google.com/` または
`https://github.com/google/fonts/tree/main/ofl/<名前>` から入手できる。

### 有料フォント（印刷所やデザイナーが持っている可能性がある）

日本で「高級感のある明朝」といえば、まずこのあたり。
外注先に**「筑紫オールド明朝は使えますか」と聞いてみる価値がある。**

- **筑紫オールド明朝**（フォントワークス）── 高級感といえばまずこれ
- **游明朝体36ポかな**（字游工房）── かなが美しい
- **秀英明朝**（大日本印刷）
- **リュウミン／黎ミン**（モリサワ）

## 印刷に出すときの注意

- **塗り足し（ぬりたし／bleed）は入っていません。**仕上がり実寸です。
  印刷所から「塗り足し3mm」を求められたら、指定をいただければ付けた版を作ります。
  B案の赤い帯だけは断裁位置に掛かるため、**B案を選ぶ場合は必ず塗り足しが必要**です。
- 書体は Google Fonts の **Zen Old Mincho** と **Zen Kaku Gothic New**（ともに商用利用可・無償）。
  印刷所が持っていない場合は、PDFを渡すかアウトライン化を依頼してください。

## 旧・治療院名刺から分かったこと（2026-09-21）

以前使っていた治療院専用の名刺（`kaisha/参考_旧・治療院名刺（院長 桧物様）.pdf`）を
確認した。判明したことを記録する。

| 項目 | 旧・治療院名刺 | 外注の新校正 | 対案（A/B/C/D） |
|---|---|---|---|
| 判型 | **縦型** | 縦型 | A案が縦型／B・C・D案が横型 |
| 桧物様の肩書 | **院長** | 管理者 | 未定 |
| 住所 | 〒891-0103 皇徳寺台**三丁目**58-1 | 東谷山（会社の住所） | A/B/C＝3丁目／**D＝三丁目** |
| TEL / FAX | ともに 099-296-9843 | 9844 / 9843 | ともに 9843 |
| 会社名 | **入っていない** | 入っている | 入っている（4案とも） |
| 色 | 緑（ハーベストの色） | 白＋緑 | 白＋赤 |

### 分かったこと

1. **縦型が既存の形。**A案（縦型）は踏襲になる
2. **桧物様は「院長」だった。**外注の新校正では「管理者」に変わっている。
   **院長のほうが対外的に強い**（ケアマネジャー様・医療機関に対して）。どちらが正か要確認
3. **住所・電話は 2026-09-19 に確定した内容と一致。**裏取りが取れた。
   ただし旧名刺は「皇徳寺台**三丁目**58-1」（漢数字）。A/B/C案とチラシは「3丁目」。
   **D案では旧名刺に合わせて「三丁目」を採った**（明朝で組むと漢数字のほうが字面が揃うため）。
   最終的にどちらかへ全部を揃える必要がある
4. **旧・治療院名刺には株式会社ハーベストが入っていない。**治療院の名刺として独立していた。
   対案（A/B/C/D）には入れてある。**外すという選択もある**が、屋号が「ハーベスト」から
   「白」に変わった以上、**地元で知られている会社名との結び付きは、むしろ書いておきたい**
   というのがD案の判断
5. **緑は「ハーベスト」の色。**屋号が「白」に変わった以上、引き継ぐ理由がない
6. **表面の上3分の1が空いている。**旧デザインの弱点で、外注の新校正もそれをそのまま
   引き継いでいた。A案はそこを「白」の一字で埋めている

## 連絡先（2026-09-19 確定）

治療院として名乗るのは**皇徳寺台のほう**、と確認が取れた。4案とも反映済み。

```
株式会社ハーベスト
〒891-0103　鹿児島市皇徳寺台3丁目58-1
TEL・FAX 099-296-9843
inc.harvest@gmail.com
```

- 郵便番号 891-0103 は日本郵便の郵便番号検索で確認した（東谷山は 891-0113）
- チラシの記載と一致している

> [!warning] IP電話への変更予定がある
> 近いうちに IP電話へ切り替える予定とのこと。番号が変わると、名刺もチラシも
> 刷り直しになる。
> - **名刺は小ロット（100〜200枚）で刷る**こと。名刺は単価が安く、刷り直しの
>   痛手が小さい。逆に「安いから」と1000枚刷ると、切り替え時に全部無駄になる
> - **チラシも同様**。配り切れる分だけ刷る
> - 切り替えの際、**今の 099-296-9843 をそのまま引き継げるか**を事業者に確認する
>   価値がある。引き継げれば刷り直しが要らない。050番号になる場合は番号が変わる
> - あわせて、**治療院専用の番号にできないか**も検討したい。今は
>   デイサービスのFAXと同じ回線のため、電話とFAXがぶつかる
