# 株式会社ハーベスト 名刺（代表・白根様の個人名刺）

**これは治療院「白」の名刺とは別物。**会社の代表としての名刺で、裏面に3事業を並記している。
外注先が作った印刷データ（303×216mm、トンボ付き、文字はアウトライン化済み）。

| ファイル | 内容 |
|---|---|
| `名刺_ハーベスト_変更前（外注データ）.pdf` | 受け取ったままの原本 |
| `名刺_ハーベスト_治療院名変更.pdf` | 治療院名だけを差し替えた版 |

## 変えたところ（1か所だけ）

裏面の3つ目の事業名。

```
鍼灸マッサージ治療院        鍼灸マッサージ治療院
ハーベスト          →      白 -HAKU-
```

**それ以外は一切触っていない。**トンボも、緑の面も、表面も、他の2事業も、
元のベクターデータのまま。

## どうやって直したか（技術メモ）

受け取ったPDFは**文字がすべてアウトライン化**されており（フォント情報ゼロ、
208個の図形パスのみ）、文字として編集できなかった。そのため、

1. 「ハーベスト」の部分だけを白で塗りつぶす
2. その位置に「白 -HAKU-」を描き直す

という方法を取った。描き直しには **Zen Kaku Gothic New Medium** を使用。
元のフォントは不明だが、4書体を並べて比べ、線の太さと字形がいちばん近いものを選んだ。

位置とサイズは、元の「ハーベスト」の実測値に合わせている。

| | 元「ハーベスト」 | 差し替え後「白 -HAKU-」 |
|---|---|---|
| 左端 | 544.08 pt | 544.02 pt |
| ベースライン | 411.28 pt | 411.28 pt |
| 文字サイズ | （実測から約6.6pt） | 6.6 pt |

> [!warning] 印刷に出す前に
> **元のフォントと完全に一致している保証はない。**近い書体を選んではいるが、
> 拡大すると字形の違いが分かる可能性がある。
>
> **確実なのは、外注先に元データ（Illustrator）で直してもらうこと。**
> 1か所の文字差し替えなので、先方にとっては数分の作業のはず。
> このPDFは「こう直してほしい」を伝える見本として使うのがよい。

## この名刺があることで決まったこと

治療院「白」の名刺（`meishi/` 直下のA・B・C案）に**関連事業を入れる必要はない。**
会社代表としての名刺がすでにこれなので、役割が分かれている。
- **この名刺** … 会社代表として。3事業を並記
- **白の名刺** … 治療院の人として。「白」に専念
